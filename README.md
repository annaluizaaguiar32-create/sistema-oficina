# Sistema de Oficina Mecânica

Projeto desenvolvido em Python para praticar programação.

## Funcionalidades

* Listar carros cadastrados
* Procurar carro pelo modelo
* Mostrar o valor total dos serviços
* Contar serviços concluídos
* Sair do programa

## Tecnologias utilizadas

* Python

## Como executar

Execute o arquivo `sistemamecanica.py` pelo terminal:

```bash
python sistemamecanica.py
```

## Objetivo

Praticar listas, laços de repetição, condicionais e operações matemáticas em Python.
